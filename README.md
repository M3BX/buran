# 📋 Документация проекта «Учёт электроэнергии (Буран)»

## 📌 Описание проекта

Веб-приложение для учёта потребления электроэнергии по боксам (индивидуальным счётчикам) и общим счётчикам «Буран 1» и «Буран 2».  
Позволяет:

- Загружать данные из JSON-файлов (показания, платежи, тарифы, уведомления).
- Добавлять произвольное количество боксов для расчёта.
- Вводить новые показания и получать расчёт расхода, начисления и долга.
- Просматривать статистику по всем боксам (таблица с фильтрацией и сортировкой).
- Смотреть детальную историю показаний, начислений и платежей по выбранному боксу.
- Отображать уведомления (alerts) при выборе определённых боксов.

Проект состоит из трёх основных страниц:

1. **index.html** – главная страница для ввода показаний и расчёта.
2. **stats.html** – страница статистики (все боксы, фильтры, сортировка).
3. **box-details.html** – детальная история по конкретному боксу.

---

## 🛠️ Технологии

- HTML5, CSS3, JavaScript (ES2020).
- Адаптивный дизайн (мобильные устройства).

## 📄 Форматы JSON-файлов

### 1. `counts.json` – показания боксов

```json
{
  "counts": [
    { "Дата": "1.12.24", "Буран": 1, "Бокс": 1, "Показания": 223 },
    { "Дата": "2.02.25", "Буран": 2, "Бокс": "1-2", "Показания": 18996 }
  ]
}
```

- `Дата` – строка в формате `д.мм.гг` (год – две последние цифры).
- `Буран` – число: 1 или 2.
- `Бокс` – идентификатор: для Буран 1 – число, для Буран 2 – строка (например, `"1-2"`, `"2-2"`).
- `Показания` – число (кВт·ч).

### 2. `pay.json` – платежи по боксам

```json
{
  "pay": [
    { "Дата": "2.12.24", "Буран": 1, "Бокс": 1, "Платёж": 130.50 }
  ]
}
```

### 3. `tarifs.json` – история тарифов

```json
{
  "tarifs": [
    { "Дата": "23.12.23", "Тариф": 7.95 },
    { "Дата": "23.07.24", "Тариф": 8.70 },
    { "Дата": "23.08.25", "Тариф": 9.80 },
    { "Дата": "23.01.26", "Тариф": 9.90 }
  ]
}
```

### 4. `alerts.json` – уведомления (опционально)

```json
{
  "alerts": [
    { "boxIds": ["9", "41", "12-2"], "message": "⚠️ Оплатить долг срочно!" },
    { "boxIds": ["*"], "message": "🔔 Общее уведомление для всех боксов" }
  ]
}
```

- `boxIds` – массив идентификаторов боксов (строки). Специальный элемент `"*"` означает «все боксы».
- Если для бокса найдено несколько записей, все они будут показаны в одном модальном окне.

## 🚀 Установка и запуск

1. Склонируйте или скопируйте все файлы в одну папку.
2. Разместите JSON-файлы в той же папке (или настройте пути в скриптах).
3. **Важно:** Для работы с `fetch` необходимо запускать страницы через локальный веб-сервер (не открывайте `file://`).  
   - Используйте **Live Server** в VS Code,  
   - или выполните в терминале:  
     ```bash
     python -m http.server 8000
     ```
     затем откройте `http://localhost:8000`.
4. Откройте `index.html` в браузере.

## 🖥️ Функциональность страниц

### index.html – главная

- **Добавление боксов**: кнопка «+ Добавить бокс» создаёт новый блок с выбором Бурана и Бокса.
- **Ввод новых показаний**: поле ввода, подсказка с последним показанием из JSON.
- **Сохранение состояния**: выбранные боксы сохраняются в `localStorage` (введённые показания не сохраняются).
- **Расчёт**: кнопка «Рассчитать →» показывает модальное окно с:
  - Расходом по каждому боксу.
  - Начислением по текущему тарифу (на сегодня).
  - Текущим долгом (до новых показаний).
  - Общими итогами.
- **Уведомления**: при выборе бокса (или восстановлении сохранённого) проверяется `alerts.json` и показывается модальное окно с сообщениями.

### stats.html – статистика

- **Таблица** со столбцами: Буран, Бокс, Последние показания, Последняя оплата (дата и сумма), Долг.
- **Фильтры**: по Бурану, по диапазону долга.
- **Быстрые фильтры**:
  - Не передавали показания последние 2 месяца.
  - Не оплачивали последние 2 месяца.
  - Долг > 300 руб.
- **Сортировка**: клик по любому заголовку таблицы меняет направление сортировки.
- **Общая сводка**: количество боксов, общий долг, средний долг, количество должников.

### box-details.html – детальная история бокса

- Выбор бокса через два выпадающих списка (Буран → Бокс).
- После выбора и нажатия «Показать историю» отображается:
  - Текущий баланс (долг/переплата) крупным шрифтом.
  - Хронология событий (показания, начисления, платежи) с балансом после каждого события.
- Уведомления (`alerts.json`) также показываются при загрузке истории.

## 🧩 Основные функции в `script.js`

| Функция | Описание |
|---------|----------|
| `loadAllData()` | Загружает `counts.json`, `pay.json`, `tarifs.json`, `alerts.json`. |
| `createBoxItem()` | Создаёт DOM-блок для выбора Бурана/Бокса и ввода показаний. |
| `saveBoxesToStorage()` | Сохраняет выбранные боксы (буран+бокс) в `localStorage`. |
| `calculateTotal()` | Выполняет общий расчёт по всем блокам и показывает модальное окно. |
| `showAlertsForBox(boxId)` | Находит уведомления для бокса и показывает их в модальном окне. |
| `getLastReading()` | Возвращает последнее показание для бокса из `counts.json`. |
| `getDebt()` | Рассчитывает историю долга с учётом начислений и платежей. |

## 🔧 Настройка и кастомизация

- **Изменить тарифы**: отредактируйте `tarifs.json`.
- **Добавить уведомления**: создайте `alerts.json` с массивом объектов.
- **Изменить внешний вид**: правите `style.css`.
- **Локализация** (даты, валюта): используется русский язык и символ рубля; даты парсятся в формате `д.мм.гг`.

## ❗ Возможные проблемы и решения

| Проблема | Решение |
|----------|---------|
| Страница не загружается, ошибка `fetch` | Запустите через локальный веб-сервер (не `file://`). |
| Не показываются показания в placeholder | Проверьте, что `counts.json` содержит записи для выбранного Бурана/Бокса. |
| Долг не считается | Убедитесь, что есть хотя бы два показания для бокса (расход) и тарифы в `tarifs.json`. |
| Уведомления не появляются | Создайте `alerts.json` и проверьте, что `boxIds` совпадают со строковыми идентификаторами боксов. |
